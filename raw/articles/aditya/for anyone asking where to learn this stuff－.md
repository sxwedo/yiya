for anyone asking where to learn this stuff:

• RAG → [weaviate.io/blog/introduct…](https://weaviate.io/blog/introduction-to-rag)
• Agentic RAG → [weaviate.io/blog/what-is-a…](https://weaviate.io/blog/what-is-agentic-rag)
• AI Agents → [anthropic.com/research/build…](https://www.anthropic.com/research/building-effective-agents)
• Multi-Agent Systems → [resources.anthropic.com/building-effec…](https://resources.anthropic.com/building-effective-ai-agents)
• LangGraph → [docs.langchain.com/oss/python/lan…](https://docs.langchain.com/oss/python/langgraph/overview)
• LangGraph (code) → [github.com/langchain-ai/l…](https://github.com/langchain-ai/langgraph)
• MCP → [modelcontextprotocol.io](https://modelcontextprotocol.io)
• Memory Systems → [letta.com](https://www.letta.com)
• Evals → [docs.smith.langchain.com](https://docs.smith.langchain.com)
• Context Engineering → search "Context Engineering Survey" on arXiv

and please skip the "build an ai agent in 10 minutes" videos
build something, watch it fail, then figure out why.
