# 📰 ChatGPT Codex 手机号二次验证的解决方法


为了写这个教程，我专门开了蓝，因为不开蓝v，发不了那么多图片，这个教程虽然简单，但是容易出错。
我自己14个ChatGPT账号，全都是我自己的google账号注册的，两个plus会员，然后用 cockpit tools 来管理，平时用的时候，很方便切换，但是有一天，突然出现这种情况：

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_16.png)

然后，再次授权的时候，提示我要手机号。然后就跟着x上面的众多网友一起接码平台开始买手机号验证，12个全都验证了，然后前几天就悲剧了，陆陆续续开始，要我二次手机号验证。
我一开始想到的时候注销ChatGPT账号，因为手机号肯定是找不回来了，但是如果我注销，一个月后还可以用同样的google账号再次申请，无非就是花钱买海外eSIM手机号呗，英国的giffgaff卡，德国的沃达丰等等。


然后我今天登录ChatGPT网页端，突然找到了解决办法，就是它：

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_7.jpg)

- 看到上面的文字了吗？禁用电子邮件和短信登录验证码。







第一步，你如果没有设置过这个，你打开安全这一栏，高级安全设置，高级账号安全右边是注册按钮，点击注册。

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_10.jpg)

第二步，内页再点击注册

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_6.png)

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_8.png)

然后点击加入








![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_14.jpg)

这里要你登录你验证登录你的ChatGPT账号，你可以选择发送邮件验证码来登录，如果你之前设置了 Authenticator app，还需要二次验证，没设置就一次验证就可以了。



![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_15.png)

验证通过后，你就会来到这个页面，让你设置，点击继续




![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_12.png)

然后就是这个页面，这里很多人会出错，先点第一个方式，点击添加



然后

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_9.png)

然后选择第一个，通行密钥






注意！注意！

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_11.jpg)

如果你看到这个页面，但是不知道这是什么？你可以点击取消，点击取消后，

![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_2.jpg)

你会看到这个，然后选择第一个，google 密码管理工具，点击



![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_3.jpg)

点击创建就可以了。



![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_13.jpg)

然后添加第二种方法，依然选择通行密钥，然后选择您的chrome 个人资料



![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_1.jpg)

输入密码创建就可以了




![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_5.jpg)

两种方法创建后就可以点击继续了



![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_17.jpg)

然后下载你的密钥，选择下面的我已保存我的恢复密钥，点击继续，继续







![Image](../_media/x-2061534208926102003/tigeryan718_2061534208926102003_4.jpg)

然后你的高级账号安全就创建完成了，各位你看到上面的文字了吗？你的电子邮件验证码，短信验证码都会被禁用，各位，到此，你再也不用短信验证码了！！

你的账号可以随意退出和登录了！
