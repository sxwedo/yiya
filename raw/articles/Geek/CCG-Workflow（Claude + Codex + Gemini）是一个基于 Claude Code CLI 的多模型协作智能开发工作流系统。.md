CCG-Workflow（Claude + Codex + Gemini）是一个基于 Claude Code CLI 的多模型协作智能开发工作流系统。

终于可以躺平让 AI 互相扇巴掌了，这东西本质上就是个“赛博奴隶主模拟器”。它把 Claude 那个自以为是的家伙架在中间当监工，然后把 Codex 和 Gemini 关进小黑屋给它打工。。。
