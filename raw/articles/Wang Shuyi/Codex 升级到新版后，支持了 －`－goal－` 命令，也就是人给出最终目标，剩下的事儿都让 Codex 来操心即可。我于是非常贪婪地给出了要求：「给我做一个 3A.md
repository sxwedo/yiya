OpenAI 给 Codex CLI 加了个很狠的新东西：
/goal
你给它一个目标，它就会一直跑。
跨多轮不丢，不达目的不停。
这是 0.128.0 的新功能。
先在 \~/.codex/config.toml 里打开：

\[features\]
goals = true

目前只有 CLI 有，桌面 App 还没跟上。
以前得自己搓脚本、外挂记忆、还要敲一长串危险参数。
现在直接 /goal。
Codex，越来越像真 Agent 了。
