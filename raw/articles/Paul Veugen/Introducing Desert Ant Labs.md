# Introducing Desert Ant Labs

Paul Veugen, 2026-09-08。原文：<https://desertant.com/blog/introducing-desert-ant-labs/>

要点（据抓取）：

- 欧洲实验室，做**端侧**小模型：音频/视觉/文本，毫秒级、无 token 费；一个任务一个模型。
- 首发约 18 个模型（Swift / Kotlin / JS SDK）。例：Voz 转录快于 Whisper；Clear 9MB 音频增强；Redact 端侧 PII；Tongue 2MB 语种识别。
- 动机：自家视频应用 Detail 上云 API 账单；在 Hugging Face 找不到可直接装进产品的端侧模型，于是自训。
- 主张：数据不出设备；免费额度到 10 万月活设备。
