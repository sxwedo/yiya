1\.  Panniantong/Agent-Reach

给 AI Agent 装上全网眼睛。Twitter、Reddit、YouTube、GitHub、B 站、小红书……一键读取，零 API 费用，自愈路由

以前 Agent 被关在笼子里，现在直接打开整个互联网。情报战时代真正落地！

2\.  Leonxlnx/taste-skill

给 AI 装上「审美品味」。告别千篇一律的 slop 前端，强制布局、字体、动效、密度全部升级。

🔗 直[github.com/Leonxlnx/taste…](https://github.com/Leonxlnx/taste-skill)ec

终于不用再看 Agent 生成的塑料感 UI 了，直接出有设计感的作品。前端生产力质变！

3\.  calesthio/OpenMontage

世界首个开源 Agentic 视频制作系统。12 条流水线 + 52 种工具，描述一句话，Agent 自己研究、写脚本、生成素材、剪辑出片。

🔗 [github.com/calesthio/Open…](https://github.com/calesthio/OpenMontage)JsD

一个人顶整个视频团队，含金量直接爆表。

4\.  microsoft/markitdown

微软亲儿子级文档预处理神器。PDF / Word / PPT / Excel / 音视频一键转干净 Markdown，专为 LLM 喂料设计。

🔗[github.com/microsoft/mark…](https://github.com/microsoft/markitdown)yosg

Agent 吃料再也不用手动清洗了，预处理层事实标配。

5\.  DeusData/codebase-memory-mcp 
把整个代码库变成持久知识图谱的 MCP 服务器。Agent 再也不用每次重新「读」项目。

🔗 直达：[github.com/DeusData/codeb…](https://github.com/DeusData/codebase-memory-mcp)

长期项目记忆终于有了真正可用的基础设施。
