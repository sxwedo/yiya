GitHub CLI算是一个比较重要很多很多人使用Agent的时候都可能用的到一个CLI，我又整理了几个大厂比较常用的CLI。

1、飞书官方CLI： [github.com/larksuite/cli](https://github.com/larksuite/cli)    

2、钉钉 CLI： [github.com/DingTalk-Real-…](https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli)

3、企业微信CLI：[github.com/WecomTeam/weco…](https://github.com/WecomTeam/wecom-cli)

4、Obsidian CLI ：[obsidian.md/zh/cli](https://obsidian.md/zh/cli)

5、Cloudflare Wrangler CLI:   [developers.cloudflare.com/workers/wrangl…](https://developers.cloudflare.com/workers/wrangler/)

6、Vercel CLI： [vercel.com/docs/cli](https://vercel.com/docs/cli)

7、Google CLI：[github.com/googleworkspac…](https://github.com/googleworkspace/cli)

8、AutoCLI：它是一个给 Claude Code（或其他 AI Agent）安装的 Skill 包，让 Agent 能通过一个轻量 CLI 工具直接访问 55+ 个网站的实时数据。 [github.com/nashsu/AutoCLI…](https://github.com/nashsu/AutoCLI-skill)

8、CLI-Anything:  一条命令，把任何软件自动转化成 AI Agent 可以直接操控的 CLI 工具 [github.com/HKUDS/CLI-Anyt…](https://github.com/HKUDS/CLI-Anything)

9、OpenCLI  把任何网站、Electron App、本地工具，都变成可被 AI Agent 调用的标准化 CLI 接口。 [github.com/jackwener/Open…](https://github.com/jackwener/OpenCLI)
