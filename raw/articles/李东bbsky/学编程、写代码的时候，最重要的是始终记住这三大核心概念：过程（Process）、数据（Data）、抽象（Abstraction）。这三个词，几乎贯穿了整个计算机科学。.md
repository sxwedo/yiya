学编程、写代码的时候，最重要的是始终记住这三大核心概念：过程（Process）、数据（Data）、抽象（Abstraction）。这三个词，几乎贯穿了整个计算机科学。

过程代表程序的逻辑与行动，它体现在循环、判断、函数、算法等中。

而一切程序都围绕“数据”展开，程序的状态、输入、输出、存储、传输都属于数据的流动。一个好程序员，永远从数据结构思考问题。

抽象就是屏蔽细节、暴露本质、简化复杂性的方法，也是程序员编程能力的上限：
1️⃣ 函数是对行为的抽象；
2️⃣ 类是对对象的抽象；
3️⃣ 模块是对功能的抽象；
4️⃣ API 是对系统交互的抽象；
5️⃣ 框架，是对常见模式的抽象。

《How to Design Programs》提出的设计方法是：先定义数据，再设计操作数据的函数，最后建立抽象层。这是程序设计的黄金路线。
SICP也明确分 “用过程构建抽象”与“用数据构建抽象”两大篇章。

是的，不过这里说的数据更为广泛，它包括：
1、显式数据：过程输入的数据形态，如字面量、变量、数据结构、参数与返回值、持久化数据；
2、隐式数据：驱动过程的选择与结果，如状态、上下文、闭包里的变量、控制流、消息；
3、抽象数据：ADT、Model、Schema、序列化
有时候数据还分布在不同层级、不同介质中，以不同形式支撑整个系统：
1、客户端数据：cookie、local storage、IndexDB等；
2、会话数据：Server Session和Token Session；
3、缓存数据
4、持久化数据：数据库、文件存储
5、传输数据：JSON、gRPC等
6、运行时数据
7、日志与分析数据
数据也可以是开发应用程序时需要具备的数据优先思维，也就是所有App的功能最终都可以还原为数据模型的变化轨迹，要先对数据建模。
总之，就是无时无刻都要想着数据这个重要的概念。
