# Identity

<https://obsidian.md/> 本地优先 Markdown 笔记：vault 即文件夹，`[[wikilink]]` 互链，图谱看枢纽与孤儿。插件（Clipper、Dataview、Marp）可选用，不是必须。

## Mechanism

在 [LLM Wiki](../concepts/llm-wiki.md) 里分工是：**Obsidian 当 IDE，LLM 当程序员，wiki 当代码库**。[yiya](./yiya.md) 同样是 git 上的 markdown，给人浏览、给 Agent 维护。主题仓（AnuPpuccin、Cupertino、Minimal、kepano skills）是皮肤/技能书签，不是第二套产品。

## Boundaries

不是编码代理 harness，不是云笔记同步盘，不是 [Proof](../../domains/agents/entities/proof.md) 那种人机共写编辑器。教程/插件合集顺带点名不在本页展开。
