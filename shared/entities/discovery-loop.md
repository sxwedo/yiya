# Identity

<https://www.discoveryloop.com/> 要把科学方法那一圈自动化：提出实验 → 实现并跑 → 看结果 → 再迭代。先拿机器学习研究当客户，再扩到可度量的科学与工程。创始团队：Jeff Dean、Sanjay Ghemawat、Quoc Le、Oriol Vinyals。

## Boundaries

实验室/公司，不是编码代理 harness。人主导的评测纪律见 [评测驱动开发](../../domains/engineering/concepts/eval-driven-development.md)。前东家脉络 [Google DeepMind](./deepmind.md)。本页原料是站点介绍，不编内部评测栈。
