# Summary

**Discovery Loop**（https://www.discoveryloop.com/）要自动化科学方法里那一圈：提出实验 → 实现并跑 → 看结果 → 再迭代。用前沿模型和大规模算力并行成千上万次评测，先拿机器学习研究当自己的第一个客户，再扩到其他可度量的科学与工程问题。创始团队：Jeff Dean、Sanjay Ghemawat、Quoc Le、Oriol Vinyals。

定位：实验室/公司，不是编码代理 harness。前东家脉络见 [Google DeepMind](./deepmind.md)；人主导的评测纪律见 [评测驱动开发](../../domains/engineering/concepts/eval-driven-development.md)（Discovery Loop 要把整圈实验自动化）。
