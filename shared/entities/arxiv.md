# Summary

**arXiv**（<https://arxiv.org/>）是康奈尔大学运营的预印本库：作者上传、按学科分类公开，不经传统期刊审稿即可检索。本库当**文献源**：从这里点名单篇再成文入库，不把首页或整站当知识正文，也不开「论文域」。
