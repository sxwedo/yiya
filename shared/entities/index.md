# entities

* [Andrej Karpathy](./karpathy.md) — 提出 LLM Wiki 模式：用 LLM 增量维护个人知识库，而非每次 RAG 重挖。
* [Google DeepMind](./deepmind.md) — Google 的 AI 研究实验室：公开入口覆盖 Gemini/Gemma 等模型，以及科学发现与机器人方向。
* [Discovery Loop](./discovery-loop.md) — 自动化实验闭环以加速科学与工程：提出、跑、从评测里学；先从机器学习研究做起。
* [Grokipedia](./grokipedia.md) — xAI 用 Grok 生成并核验的在线百科（grokipedia.com）：公开条目、不可直接众包编辑；不是个人 LLM Wiki。
* [Hacker News](./hacker-news.md) — Y Combinator 的黑客新闻板：用户提交链接与讨论；Show HN / Ask HN。跨域外探源，不是本库知识页。
* [Obsidian](./obsidian.md) — 本地优先的 Markdown 知识库：vault 即文件夹，双向链接与图谱；Karpathy 把 LLM Wiki 的人读面叫成 IDE。
* [yiya](./yiya.md) — 个人知识库：LLM Wiki 流程 + OKF + Domain
* [llmwiki](./llmwiki.md) — Karpathy LLM Wiki 的开源实现
* [科技爱好者周刊](./ruanyf-weekly.md) — 阮一峰每周科技周刊
* [史记知识库](./shiji-kb.md) — 《史记》→ 可交互知识图谱与 wiki
* [HelloGitHub](./hellogithub.md) — 入门级有趣 GitHub 项目月刊
* [awesome](./awesome.md) — 各主题 awesome 列表总索引
* [Github Ranking](./github-ranking.md) — GitHub star / fork 排行
* [arXiv](./arxiv.md) — 康奈尔预印本库：公开论文、按学科分类；跨域文献源，不是本库知识页。
