# Summary

**Amp**（<https://ampcode.com>）自称面向前沿模型的 coding agent 与开发环境。核心产品概念是 **Orb**：每个 agent 线程一台可远程控制的机器，带上代码、插件与工具；合上笔记本后仍继续跑，可从 Web / 终端 / 手机接回。宣传能力包括门户内实时预览改动、任意设备审阅与改文件、事件/日程唤醒、团队多人共控同一 Orb，以及共享终端会话。

定位：远程 agent 运行时 + 开发壳，不是本机终端会话持有器（对照 [Herdr](./herdr.md)）也不是本机多会话工作台（对照 [Termany](./termany.md)）。**未灌站**。
