# Summary

**Termany**（https://termany.sh/）是面向编码代理的终端工作区：会话（工作中/完成/需关注）、旁路审阅（文件/diff/对话/浏览器）、worktree 与 SSH、以及 Claude Code / Codex 用量与成本看板，装在同一本地窗口。内置多主题与可重绑操作；macOS / Windows / Linux 桌面端。

定位：agent 会话与终端的**工作台壳**，不是又一款 coding agent；本机多产品启动壳见 [mena](./mena.md)，极简 harness 见 [Pi](./pi.md)。
