# Summary

**AIradar**（<https://airadar.vip>）是面向 AI 订阅的**选购与续费比价站**：按产品（ChatGPT / Claude / Gemini / Grok / Cursor 等）汇总商家公开标价，并区分代充、成品账号、共享席位等交付形态与质保/兑换期限等条件；站内也提示低价引流与私下加价风险。

定位：报价与条件对照入口，**不是**官方商店，也不背书第三方卖家。库内只收站点本身，不拆店铺或单条报价。
