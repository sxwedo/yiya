# Summary

**Archify**（[tt-a1i/archify](https://github.com/tt-a1i/archify)）让 agent 产出类型化 JSON IR，再确定性编译成 HTML/SVG 系统图（多种图类、主题、前后 diff）。可 `npx skills add tt-a1i/archify`。面向 Cursor / Claude Code / Codex / OpenCode。

对照：[Graphify](./graphify.md) / [CodeGraph](./codegraph.md) 是代码知识图谱产品；Archify 是聊天里出可演示架构图的 Skill。发现层见 [skills.sh](./skills-sh.md)。
