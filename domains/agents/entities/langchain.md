# Summary

**LangChain**（https://www.langchain.com）提供从开源框架到工程平台的 agent 栈：快速模板（langchain）、低层可控图（LangGraph）、长程自治（deepagents），以及 LangSmith（构建/评测/部署/监控/治理）。定位偏「产品化 agent 工程平台」，与本库单 harness（Pi 等）互补。
