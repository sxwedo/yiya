# Summary

**Omarchy**（https://omarchy.org）是 DHH / 37signals 一侧的「omakase」Linux 桌面：基于 Arch + Hyprland（近期桌面壳多为 Quickshell），把 Claude Code / Codex / Pi / oh-my-pi 等 CLI coding agent 预接线为懒加载启动器，并自带可让 agent 改系统配置的默认 skill。

定位：整机开发环境 + agent 运行面，不是又一款独立 harness；本库单产品仍见 [Pi](./pi.md)、[oh-my-pi](./oh-my-pi.md)，本机多产品壳见 [mena](./mena.md)。
