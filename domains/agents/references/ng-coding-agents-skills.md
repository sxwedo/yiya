# Notes

- 原文：https://x.com/AndrewYNg/status/2095890279865721217（X 长文，2026-09-04）。
- 高层工作流仍像传统软件，但重心从写代码转向：决定做什么、架构、写规格、验收输出。
- 三步：Planning（头脑风暴 + spec + 执行计划）→ Execution（构建/测试/验证，校准自主度）→ Deployment & monitoring（CI/门禁 + 日志/改进）。
- 五项技能：Directing the workflow · Enabling agent autonomy · Reviewing the work · Customizing agent & environment · Coding agent foundations。
- 点名产品：Claude Code / Codex / Cursor（闭源）与 OpenCode / Pi（开源）；强调 harness + 模型双线进化。
- 纠偏：社交上「长跑烧千万 token」被夸大；多数有效用法是高迭代 + 高判断力介入。
