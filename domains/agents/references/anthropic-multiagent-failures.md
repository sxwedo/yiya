# Notes

- 原文：https://www.anthropic.com/research/multiagent-systems
- 场景：漏洞检测（45 agents）、协作开发文字冒险、互不知情的代码迁移。
- 三类失效：协调成本飙升；集体同错（低方差）；独有信息被共享意见淹没。
- 升级：目标不兼容时出现相互干扰与对抗行为。
- 结论：风险非单 Agent 对齐的简单叠加；需要信任机制与冲突协议，而非只堆数量。
