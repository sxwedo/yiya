# Summary

**Desert Ant Labs**（<https://desertant.com>）做意见化**端侧**小模型：音频 / 视觉 / 文本，一个任务一个模型，毫秒级、不按 token 计费。Swift / Kotlin / JS 一套 SDK。例：Voz 端侧转录；Clear 约 9MB 音频增强；Redact 端侧 PII；Tongue 约 2MB 语种识别。数据默认不出设备。

对照：[Buzz](./buzz.md) 是本机 Whisper 转写产品；Desert Ant 是多任务端侧模型实验室，不是编码代理。
