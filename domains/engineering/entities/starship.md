# Summary

**Starship**（https://starship.rs/）是跨 shell 提示符：用 Rust 写成，bash / zsh / fish / PowerShell 等共用 `starship.toml`。显示 git、语言版本、云上下文等模块，默认开箱即用、可关可配。

定位：终端外观与状态条，不是 harness、不是 Docker。本库先收产品入口；安装/配置细则等有单篇指南再成文。
