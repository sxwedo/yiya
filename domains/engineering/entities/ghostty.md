# Summary

**Ghostty**（https://ghostty.org/）是终端**模拟器**：Zig 核心、GPU 渲染，macOS/Linux 用平台原生 UI（不是 Electron）。可嵌入（libghostty）。

定位：跑 shell 的窗口，不是 harness。提示符层见 [Starship](./starship.md)（跨 shell 状态条，跑在终端里）。
