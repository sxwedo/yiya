# Identity

**balenaEtcher**（<https://etcher.balena.io/>）是 balena 出品的开源镜像刷写桌面应用：从本地文件或 URL 选取镜像，选目标盘，一键 Flash，并在写入后校验。Windows / macOS / Linux；面向制作可启动安装介质、刷嵌入式/树莓派系统镜像等场景。默认隐藏大容量/系统盘并给出警告，避免误写硬盘。

定位：专用**刷盘工具**，不是分区管理器或通用烧录套件。源码见 <https://github.com/balena-io/etcher>。
