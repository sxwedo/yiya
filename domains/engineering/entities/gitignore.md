# Summary

**github/gitignore**（https://github.com/github/gitignore）是 GitHub 官方的 `.gitignore` 模板仓库：根目录按语言/框架放模板，`Global/` 放编辑器与操作系统规则，`community/` 放尚未晋升的社区模板。新建仓库时的语言模板多来自这里。
