# Definition

**X 自媒体增长**（Roland.W 2026.09 开源指南）：自媒体本质是被看见、夺回叙事主权；社交媒体本质是社交在场——公开站队，带摩擦。增长不是堆同质「Codex 技巧」清单。

1. **主页先行。** Bio / 头像 / 背景在 3 秒内回答：你是谁、做什么、为何关注。用具体锚（行业、成绩）代替空心人设。时间线还没刷到，主页已经筛人。
2. **一致性。** 2～3 个主题长期发声；立场不墙头草；语气尽量真人；节奏持续在场。吸引同类，不讨好所有人。
3. **价值。** 命中对方当下具体困境，优于高密度信息。一次一形：信息 / 框架 / 情绪 / 行动。读者要视角和判断，不是再一份通稿。
4. **情感。** 在一致性和价值之上露出真人瑕疵与反思，形成长期连接。
5. **传播。** 让好内容拿到第一波传播。**忌 AI 自动发推伤品牌**——在场被识破成流水线，信任先没。

放在 `engineering`：偏运营方法，不是 coding-agent harness。若「创作者/增长」以后成簇，再议新 Domain。
