# Notes

- 现象：AI 编码提速后，端到端交付体感未同步变快；P85 曾顽固停在多迭代外。
- 公式：组织效率 = 价值创造时间 /（价值创造时间 + 组织摩擦时间）。
- PM 转向：过程管理 → 效率治理；AI 做态势感知与问题曝光，PM 推动解决与长效治理。
- 路径：统一项目语义 → 数据可见可信 → 异常定位 → 瓶颈挖掘（PM-Skills 作能力节点）。
- 结果（文中）：中位 19→9 天；P85 52→23 天；>30 天长尾 35%→7%。
