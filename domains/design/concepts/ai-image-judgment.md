# Definition

**AI 生图判断**（南鸢重写入门课的理由）：今天普通人的入口是对话框 + 中文想法 + 参考图 + 几轮局部改，不是 Stable Diffusion 参数表。社交上的长 Prompt / JSON 容易复制，空白时仍不知道第一句写什么。

Prompt 重要，但不是最重要。短词也可能碰巧好看——模型补了站位、光、材质、情绪。真正的墙在下一步：喜欢一半时能否说出保留什么；只觉得「怪」时能否把怪说清；同一句第二次完全不同，是波动还是选错工具；偶然成功后能否做出第二张，而不是再抽卡。缺的是看图、判断、继续沟通，不是下一条咒语。

课的路径：先弄清生图 / 模型 / Prompt、写下第一段、看模型听懂了什么再改；主线再接主体与关系、机位、光、色、材质、风格——问题出现时才讲（人挤画面正中才讲构图，水手服画成塑料才讲材质）。人物一致性要分清身份 vs 这张妆造姿态；系列要有不变关系也要给每张变化。成功图只证明可能；失败到修正才把哪一步坏了讲明白。

用 GPT Image 2、Grok Imagine 等举例，**不把方法绑死在一个模型上**。留下换工具仍能用的眼睛。已有成熟方法论的人不必再买一套入门。

## Boundaries

不是 [人像角色设定](./portrait-character-brief.md) 那套骨相妆发 Skill，也不是 [AI 人像美姿提示词](./ai-portrait-posing.md)。不是 UI De-slop。课程入口（VSC / 社群）是销售渠道，本页只收判断方法。不保证每张图听话，不承诺个人风格。
