# Identity

**personal-site-builder**（[SpaceZephyr/personal-site-builder](https://github.com/SpaceZephyr/personal-site-builder)，空格.space）：Agent Skill。卡点不是「不会写代码」，是材料散、风格不会定、不敢上线。它读简历、社交主页、作品集；对话整理内容、选风格、部署。

## Mechanism

有什么给什么（简历 / GitHub / 公众号 / 小红书 / 链接）。确认后选视觉：极简黑白、编辑排版、终端极客、Bento、杂志标题、暖色手作。分析字体、字号、颜色、间距、内容宽度、圆角、明暗，再套到你的资料。完成后查不同宽度、明暗、文字溢出、控制台错误、占位符和假数据。发布前说明平台、仓库、哪些联系方式会公开。文建议 GitHub + Vercel。先上名片，有项目再加案例。

## Boundaries

不是通用建站平台，不是 De-slop 纪律本身。人还是要说清「你是谁」。本页不是 Vercel 手册。
